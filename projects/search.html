SEARCH

SEARCH в стиле OpenVMS: показывает записи файлов с заданными строками.

ВерсияX01-32
СтатусПоддерживается
ПлатформыLinux
ЛицензияApache License 2.0
Для когоТем, кому привычен OpenVMS SEARCH: комбинации строк AND/OR, номера строк, заголовки по файлам.

Что это

Строка поиска - простая подстрока, без регулярных выражений. Спецификацию файлов утилита раскрывает сама, поэтому её берут в кавычки.

Зачем

Повторить поведение SEARCH из OpenVMS на Linux.

Quick start Пример

search '*.c' alpha,beta /MATCH=AND /NUMBERS
search 'src/*.c,include/*.h' STS$K_
