BroAgent

Агент обратного соединения для BroProxy: машина за NAT сама звонит прокси.

ВерсияX.01-10ECO07 (по README)
СтатусАктивная разработка (в одном репозитории с BroProxy)
ПлатформыLinux: те же процессоры, что у BroProxy
ЛицензияApache License 2.0
Для когоТем, чья машина с выходом в Интернет находится за NAT, файрволом или мобильным оператором и не принимает входящих соединений.

Что это

BroAgent сам открывает все соединения к BroProxy; на машине агента не открывается ни один порт. Если входящее правило возможно, агент не нужен: хватит записи в файле bproxy.peers на стороне прокси.

Зачем

Дать прокси выход через узел, до которого нельзя дозвониться.

Quick start Установка

apt install ./bagent_<версия>_arm64.deb     # имя файла - как в Releases
# поправьте /etc/bagent/ (пароли в образцах - <password>), затем запустите сервис
