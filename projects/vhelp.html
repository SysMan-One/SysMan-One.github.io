HELP (vHELP)

Справочная подсистема в стиле OpenVMS: библиотекарь Markdown и браузер.

ВерсияX01-35
СтатусАктивная разработка
ПлатформыLinux
ЛицензияApache License 2.0
Для когоАвторам утилит командной строки, которым нужна иерархическая справка HELP, как в OpenVMS.

Что это

vhelptran переводит Markdown в библиотеку справки, vhelp ходит по ней по темам. Обратная операция (/EXTRACT) возвращает текст, и после первого прохода цикл извлечь-перевести стабилен.

Зачем

Все наши пакеты поставляют справку через неё.

Quick start Пример

vhelptran doc/helplib.md /OUTPUT=helplib.hlb /IDENT=X-01
vhelp submit /after
vhelptran /EXTRACT helplib.hlb /KEY="VHELPTRAN SOURCE FORMAT"
