MSCP-Hub

MSCP-сервер дисков для узлов OpenVMS, работающий на Linux.

ВерсияX01-24ECO2 (тег)
СтатусАктивная разработка
ПлатформыLinux, ядро 5.10+ (io_uring); Raspberry Pi, NaPi-C
ЛицензияGNU GPL v3
Для когоВладельцам домашнего или учебного VMScluster, которые хотят хранить диски OpenVMS на современных носителях.

Что это

MSCP-Hub позволяет узлам OpenVMS в одной локальной сети использовать файлы и блочные устройства Linux как собственные диски. Для OpenVMS это контроллер дисков в стиле HSC по протоколу NISCA (PEDRIVER); членом кластера сервер не является.

До 8 дисков на сервер (файлы или блочные устройства, секторы 512 или 4096), READ, WRITE, ERASE и COMPARE, io_uring с fdatasync до ответа на WRITE, юнит systemd, счётчики в MHMON, T4 и Modbus/TCP. Сервер около 300 КБ.

Зачем

Наследие VMScluster и инженерная культура DEC стоит сохранить: проект мал, каждое решение в нём записано, он годится как курс для студентов; сообщения, HELP и документация сделаны по-DEC-овски.

Quick start Сборка и установка

# нужны StarLet 1.6+ и liburing (apt install liburing-dev)
cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure
cmake --install build
