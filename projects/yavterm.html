yaVTERM

Небольшой шифрованный терминальный туннель для OpenVMS, замена SSH.

Версияуточняется
СтатусРабочий, развивается
ПлатформыКлиент - Linux; сервер - OpenVMS Alpha (и I64)
ЛицензияApache License 2.0
Для когоПользователям OpenVMS, чей штатный SSH-сервер требует устаревших алгоритмов или неверно печатает эхо.

Что это

Туннель с нуля: все криптопримитивы (X25519, Salsa20, Poly1305, BLAKE2b) написаны вручную на переносимом C, потому что для VMS/Alpha нет libsodium. Рукопожатие в духе Noise-NK: клиент знает статический открытый ключ сервера и запоминает его для host:port, как known_hosts. Пользователя проверяет обычный вход OpenVMS (Username/Password) уже внутри туннеля.

Клиенты: vtc (терминал) и vtcp (копирование файлов). Сервер работает на OpenVMS как отсоединённый процесс. Спецификация протокола - PROTOCOL.md.

Зачем

Создан для гостя OpenVMS Alpha под AlphaEmu, но к нему не привязан: работает с любым хостом OpenVMS, на котором запущен сервер.

Quick start Сборка клиента на Linux

# нужны установленные StarLet и HELP
cmake -S . -B build
cmake --build build          # build/vtc, build/vtcp
cmake --install build        # /opt/yavterm
vhelp yavterm                # обзор, ключи, сообщения

Источник: yaVTERM/README.md; серверная часть собирается на VMS через build.com
