yaDNSPxy

Кэширующий DNS-форвардер для встраиваемого роутера: наружу по DoT, DoH, DoQ или обычному UDP/TCP.

Версияуточняется
СтатусВ разработке
ПлатформыOpenWrt, NapiLinux (Linux)
ЛицензияApache License 2.0
Для когоВладельцам домашних и встраиваемых роутеров, которым нужен шифрованный апстрим для DNS.

Что это

Принимает обычный DNS из LAN и пересылает апстрим-резолверу по DoT (RFC 7858), DoH (RFC 8484), DoQ (RFC 9250) или обычному DNS. Шифрованных слушателей нет намеренно. Транспорт без библиотеки исключается из образа, а конфигурация с отсутствующим транспортом отвергается при старте.

Зачем

Лёгкая часть сквозной шифрованной цепочки для роутера.

Quick start Сборка

cmake -S . -B build -DCMAKE_PREFIX_PATH=<где установлен StarLet>
cmake --build build -j
ctest --test-dir build
