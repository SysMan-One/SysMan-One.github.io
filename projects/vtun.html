vTUN

Сетевое устройство типа tun для OpenVMS Alpha.

ВерсияX-01-02
СтатусРабочий
ПлатформыOpenVMS Alpha
ЛицензияApache License 2.0
Для когоРазработчикам, которым нужно, чтобы программа на OpenVMS стала вторым концом сетевого интерфейса (VPN и подобное).

Что это

На Linux программа открывает /dev/net/tun и становится другим концом сетевого интерфейса. vTUN даёт OpenVMS то же самое: пакеты, уходящие в интерфейс (например BE0), попадают в программу, а пакеты, записанные программой, входят в систему как пришедшие из сети.

Зачем

Основа для VPN и туннелей на OpenVMS.

Quick start Сборка

$ SET DEFAULT SYS$SYSDEVICE:[VTUN]
$ @BUILD
$ @TESTS

Источник: vTUN/README.md. Для сборки нужны три файла из лицензированных листингов исходников OpenVMS Alpha
