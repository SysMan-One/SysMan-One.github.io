BroProxy

Прокси-сервер SOCKS4/5, HTTP и HTTPS (CONNECT); один статический файл для x86, ARM и MIPS.

ВерсияX.01-10ECO17 (тег); головной коммит ECO18
СтатусАктивная разработка, выпуски по тегам
ПлатформыLinux: x86_64, armhf, arm64, mips, mipsel, mips64el; Raspberry Pi, OpenWrt
ЛицензияApache License 2.0
Для когоАдминистраторам, которым нужен лёгкий прокси на маленьком Linux-устройстве: роутере, Raspberry Pi, VPS.

Что это

BroProxy стоит между вашей программой (браузером, curl, почтовым клиентом) и Интернетом и передаёт данные в обе стороны. Понимает SOCKS4, SOCKS5, HTTP и HTTPS (метод CONNECT).

Все программы собраны статически: один файл процессора работает на любом Linux этого процессора. Готовые пакеты: .deb, .rpm, .ipk (OpenWrt 24.10 и старше), .apk (OpenWrt 25.12 и новее) и .tar.gz.

В составе: файлы пользователей, запретов, лимитов и цепочки прокси (peers) с переключением при отказе, статистика и CDR.

Зачем

Маленький, понятный и проверяемый прокси для встраиваемых устройств. Каждый комплект перед публикацией ставится и запускается в Debian, Ubuntu и OpenWrt (в том числе под qemu-user для остальных процессоров).

Quick start Установка готового пакета

apt install ./bproxy_1.10.15-1_arm64.deb          # Debian, Ubuntu, Raspberry Pi OS
dnf install ./bproxy-1.10.15-1.aarch64.rpm         # RHEL, Fedora
opkg install ./bproxy_1.10.15-1_mipsel.ipk         # OpenWrt 24.10 и старше
apk add --allow-untrusted ./bproxy_1.10.15-r1_mipsel.apk   # OpenWrt 25.12 и новее
tar -xzf BroProxy-X.01-10ECO15-arm64.tar.gz -C /   # всё остальное

# поправьте /etc/bproxy/ (пароли в образцах - <password>), затем:
systemctl start bproxy          # на OpenWrt: /etc/init.d/bproxy start
