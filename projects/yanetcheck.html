yaNetCheck

Проверка сетевого пути потоком UDP-датаграмм: потери, дубликаты, перестановки.

ВерсияX.01-28ECO01 (по архиву; README называет X.01-02)
СтатусПоддерживается
ПлатформыLinux (glibc), x86_64 и aarch64
ЛицензияApache License 2.0
Для когоТем, кто проверяет линию, коммутатор, маршрутизатор или весь путь при заданной скорости пакетов.

Что это

Отправитель шлёт UDP-датаграммы (или сырые кадры через AF_PACKET) с возрастающими номерами; приёмник считает потери, дубликаты и перестановки. Помогает отличить «пакеты не доходят до провода» от «доходят до интерфейса, но режутся локальным файрволом». Печатает периодическую статистику и переживает перезапуск любой из сторон.

Зачем

Длительные проверки до и после изменения сети.

Quick start Сборка

cmake -S . -B build -DCMAKE_PREFIX_PATH=<starlet-prefix> -DCMAKE_INSTALL_PREFIX=/usr/local
cmake --build build
ctest --test-dir build
cmake --install build
