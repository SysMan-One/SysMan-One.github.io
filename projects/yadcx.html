yaDCX

Самораспаковывающиеся комплекты для OpenVMS: один файл .BCK становится одной программой .EXE.

ВерсияX-02-00ECO01
СтатусПоддерживается
ПлатформыOpenVMS Alpha и I64
ЛицензияApache License 2.0
Для когоТем, кто передаёт BACKUP-комплекты между системами OpenVMS через FTP, почту или USB.

Что это

Файл .BCK теряет атрибуты записей при передаче через FTP, почту или веб-сервер. .EXE формата Fixed 512 проходит без потерь, а атрибуты saveset-а едут внутри. Данные сжаты стандартными процедурами DCX; перед записью проверяется CRC-32, после распаковки - второй CRC-32. Проверить комплект можно и на Linux (tools/yadcx_check.py).

Зачем

Надёжная доставка комплектов ПО на любую систему OpenVMS без дополнительных программ.

Quick start Сборка комплекта

$ BACKUP [MYAPP...]*.* MYAPP.BCK/SAVE_SET
$ YADCX MYAPP.BCK            ! создаёт MYAPP.EXE
$ YADCX /LIST MYAPP.EXE      ! показать и проверить комплект
