BATCH

Подсистема пакетных заданий для shell-скриптов - аналог SUBMIT и очередей OpenVMS.

ВерсияX-02-02ECO04
СтатусАктивная разработка
ПлатформыLinux (systemd или SysV/OpenRC)
ЛицензияApache License 2.0
Для когоАдминистраторам, которым нужны очереди заданий с номерами, состояниями и ограничением числа одновременных заданий.

Что это

Скрипт ставится в очередь и выполняется резидентным контроллером. Задание получает номер записи очереди до запуска любого процесса, может ждать слот или время старта; число одновременных заданий ограничено; аварийно завершившееся задание остаётся в очереди вместе с журналом. Два руководства: User's Guide и Programmer's Guide.

Зачем

Явная модель очереди вместо cron, привычная по OpenVMS.

Quick start Сборка и установка

cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure
sudo cmake --install build
sudo systemctl restart batchd
