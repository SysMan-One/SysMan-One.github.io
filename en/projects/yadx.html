yaDX

DX - a full-screen file manager for OpenVMS, the 2026 edition.

VersionX-02-05ECO14
StatusMaintained
PlatformsOpenVMS Alpha and I64 (checked: V8.3 Alpha, V8.4 I64)
LicenceGNU GPL v2 or later
For whomOpenVMS users on a VT100-compatible terminal.

What it is

DX (Directory eXtension) shows a directory as a list of files; you walk the list with the arrows and work through pull-down menus and one-key commands: view, edit, copy, delete, rename, protect, print, compare, run. Up to seven windows, a directory tree, sorting and filters, a group mode.

yaDX is an edition of the old DX 2.5 sources: the code is tidied, bugs are fixed, a few keys are added; the behaviour is as before. The original authors are Chau-Kuang Hung (1989-1992) and Jérôme Lauret (1994-1999).

Why

To keep a classic tool alive and buildable on current OpenVMS.

Quick start The ready-made kit

$ RUN yaDX-X-02-05ECO14.EXE        ! checks the CRC, writes DX_V29.BCK
$ BACKUP DX_V29.BCK/SAVE_SET [...] ! creates the [.DX] subdirectory
$ @[.DX]DX                         ! defines the DX command

! building from source:
$ @DX_BUILD

Source: yaDX/README.md (copy the kit to VMS in binary mode)
