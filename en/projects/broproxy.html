BroProxy

A SOCKS4/5, HTTP and HTTPS (CONNECT) proxy server; one static file for x86, ARM and MIPS.

VersionX.01-10ECO17 (tag); the head commit is ECO18
StatusActive development, releases by tag
PlatformsLinux: x86_64, armhf, arm64, mips, mipsel, mips64el; Raspberry Pi, OpenWrt
LicenceApache License 2.0
For whomAdministrators who need a light proxy on a small Linux device: a router, a Raspberry Pi, a VPS.

What it is

BroProxy stands between your program (a browser, curl, a mail client) and the Internet and passes the data both ways. It speaks SOCKS4, SOCKS5, HTTP and HTTPS (the CONNECT method).

Every program is linked statically: one file of a processor runs on any Linux of that processor. Ready-made packages: .deb, .rpm, .ipk (OpenWrt 24.10 and older), .apk (OpenWrt 25.12 and newer) and .tar.gz.

Included: files of users, bans, limits and a chain of proxies (peers) with failover, statistics and CDR.

Why

A small, clear and verifiable proxy for embedded devices. Before publication every kit is installed and started on Debian, Ubuntu and OpenWrt (under qemu-user for the other processors as well).

Quick start Installing a ready-made package

apt install ./bproxy_1.10.15-1_arm64.deb          # Debian, Ubuntu, Raspberry Pi OS
dnf install ./bproxy-1.10.15-1.aarch64.rpm         # RHEL, Fedora
opkg install ./bproxy_1.10.15-1_mipsel.ipk         # OpenWrt 24.10 and older
apk add --allow-untrusted ./bproxy_1.10.15-r1_mipsel.apk   # OpenWrt 25.12 and newer
tar -xzf BroProxy-X.01-10ECO15-arm64.tar.gz -C /   # everything else

# tune /etc/bproxy/ (the samples say <password>), then:
systemctl start bproxy          # on OpenWrt: /etc/init.d/bproxy start
