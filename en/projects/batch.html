BATCH

A batch job subsystem for shell scripts - a counterpart of OpenVMS SUBMIT and queues.

VersionX-02-02ECO04
StatusActive development
PlatformsLinux (systemd or SysV/OpenRC)
LicenceApache License 2.0
For whomAdministrators who need job queues with entry numbers, states and a limit of concurrent jobs.

What it is

A script is queued and run by a resident controller. A job gets its queue entry number before any process starts, can wait for a slot or a start time; the number of concurrent jobs is limited; a job that failed stays in the queue with its log. Two manuals: the User's Guide and the Programmer's Guide.

Why

An explicit queue model instead of cron, familiar from OpenVMS.

Quick start Build and install

cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure
sudo cmake --install build
sudo systemctl restart batchd
