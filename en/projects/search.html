SEARCH

OpenVMS-style SEARCH: shows the records of files containing the given strings.

VersionX01-32
StatusMaintained
PlatformsLinux
LicenceApache License 2.0
For whomThose used to OpenVMS SEARCH: AND/OR combinations of strings, line numbers, per-file headings.

What it is

A search string is a plain substring, no regular expressions. The utility expands the file specification itself, so it is given in quotes.

Why

To repeat the behaviour of OpenVMS SEARCH on Linux.

Quick start Example

search '*.c' alpha,beta /MATCH=AND /NUMBERS
search 'src/*.c,include/*.h' STS$K_
