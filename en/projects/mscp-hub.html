MSCP-Hub

An MSCP disk server for OpenVMS nodes, running on Linux.

VersionX01-24ECO2 (tag)
StatusActive development
PlatformsLinux, kernel 5.10+ (io_uring); Raspberry Pi, NaPi-C
LicenceGNU GPL v3
For whomOwners of a home or teaching VMScluster who want to keep OpenVMS disks on modern media.

What it is

MSCP-Hub lets OpenVMS nodes on one LAN use Linux files and block devices as their own disks. To OpenVMS it is an HSC-style disk controller speaking NISCA (PEDRIVER); the server is not a cluster member.

Up to 8 disks per server (files or block devices, 512 or 4096 byte sectors), READ, WRITE, ERASE and COMPARE, io_uring with fdatasync before a WRITE is answered, a systemd unit, counters in MHMON, T4 and Modbus/TCP. The server is about 300 KB.

Why

The VMScluster heritage and the engineering culture of DEC are worth keeping: the project is small, every decision in it is written down, it serves as a course for students; the messages, HELP and documentation are done the DEC way.

Quick start Build and install

# needs StarLet 1.6+ and liburing (apt install liburing-dev)
cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure
cmake --install build
