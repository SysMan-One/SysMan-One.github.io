vTUN

A tun-style network device for OpenVMS Alpha.

VersionX-01-02
StatusWorking
PlatformsOpenVMS Alpha
LicenceApache License 2.0
For whomDevelopers who need a program on OpenVMS to be the other end of a network interface (VPN and the like).

What it is

On Linux a program opens /dev/net/tun and becomes the other end of a network interface. vTUN gives OpenVMS the same: packets sent to the interface (BE0, for example) reach the program, and packets the program writes enter the system as if they came from the network.

Why

A base for VPNs and tunnels on OpenVMS.

Quick start Build

$ SET DEFAULT SYS$SYSDEVICE:[VTUN]
$ @BUILD
$ @TESTS

Source: vTUN/README.md. The build needs three files from the licensed OpenVMS Alpha source listings
