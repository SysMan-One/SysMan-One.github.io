yaVTERM

A small encrypted terminal tunnel for OpenVMS, a replacement of SSH.

Versionto be announced
StatusWorking, evolving
PlatformsClient - Linux; server - OpenVMS Alpha (and I64)
LicenceApache License 2.0
For whomOpenVMS users whose stock SSH server demands obsolete algorithms or echoes wrongly.

What it is

A tunnel from scratch: every crypto primitive (X25519, Salsa20, Poly1305, BLAKE2b) is written by hand in portable C, since there is no libsodium for VMS/Alpha. A Noise-NK style handshake: the client knows the static public key of the server and remembers it per host:port, like known_hosts. The user is checked by the ordinary OpenVMS login (Username/Password) inside the tunnel.

Clients: vtc (terminal) and vtcp (file copy). The server runs on OpenVMS as a detached process. The protocol specification is PROTOCOL.md.

Why

Made for the OpenVMS Alpha guest of AlphaEmu but not tied to it: works with any OpenVMS host running the server.

Quick start Building the client on Linux

# needs StarLet and HELP installed
cmake -S . -B build
cmake --build build          # build/vtc, build/vtcp
cmake --install build        # /opt/yavterm
vhelp yavterm                # overview, qualifiers, messages

Source: yaVTERM/README.md; the server is built on VMS by build.com
