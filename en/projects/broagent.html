BroAgent

The connection-back agent of BroProxy: a machine behind NAT calls the proxy itself.

VersionX.01-10ECO07 (per README)
StatusActive development (in one repository with BroProxy)
PlatformsLinux: the same processors as BroProxy
LicenceApache License 2.0
For whomThose whose machine with Internet access is behind NAT, a firewall or a mobile operator and accepts no incoming connections.

What it is

BroAgent opens every connection to BroProxy itself; no port is opened on the agent's machine. If an incoming rule is possible, the agent is not needed: a line in the bproxy.peers file on the proxy side is enough.

Why

To give the proxy a way out through a node that cannot be called.

Quick start Installation

apt install ./bagent_<version>_arm64.deb     # the file name as in Releases
# tune /etc/bagent/ (the samples say <password>), then start the service
