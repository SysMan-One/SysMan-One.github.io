yaTPU

A light text editor in the spirit of DEC TPU/EVE: plain C, termios, no ncurses.

VersionX-00-14 (per the archive)
StatusMaintained
PlatformsLinux (VT100/xterm terminal)
LicenceApache License 2.0
For whomLovers of the EDT/TPU keyboard layout on Linux.

What it is

Buffers, not files; a single input path (LEARN, REMEMBER, the .tjl journal and crash recovery with -recover); a DO prompt with abbreviations; windows follow the terminal; help in the VMS .HLP format; messages like %TPU-E-NOTFOUND. Works with UTF-8. No undo, there is RESTORE. The keycode utility shows what a key sends and how TPU names it.

Why

The editor familiar from OpenVMS where there is no ncurses.

Quick start Build

cmake -S TPU -B build-tpu && cmake --build build-tpu
./build-tpu/tpu [-recover] [-nojournal] [-keys file] [file]
./build-tpu/keycode [-normal]
